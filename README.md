# SG-MIP Scaffold Builder (SG-MSB)
Refactored, Data-Agnostic Core for the Shikshagraha MIP Transformer.

## Architecture Architecture Summary
This system isolates specific localized terminology out of prompt execution lines, routing texts through a unified, data-agnostic pipeline engine layer. 

1. **Decompose (`prompts/05-decompose.md`)**: Shatters massive text/chapters into a sequence of dependent Micro-Lesson Scaffolds (MLS Units).
2. **Optimize (`prompts/40-optimize.md`)**: Injects Connected Learning choices, peer structures, and non-monetary Participatory Budgeting resource grids.
3. **Validate**: Runs programmatic rules (Privacy guardrails, zero-device default, graph cycle validation check).

## Onboarding Disclaimer
The SG-MSB framework functions purely as an adaptive, supportive scaffolding framework for lesson content delivery. It **does not prescribe operational classroom routines**, behavior management habits, or physical school rules. The teacher remains the expert operational director of their space.\n
