# Optimization Layer Configuration

## Connected Learning Rules
* Rule CL-01 (Interest Integration): Identify passive tasks and append a discrete student-driven theme or modality option. The underlying learning milestone or mastery target must remain completely unchanged.
* Rule CL-02 (Structural Peer Roles): Convert individual administrative or clerical tracking requirements into explicit, rotating peer group roles (e.g., Measurer, Recorder, Presenter, Checker).
* Rule CL-03 (Real-World Context Mapping): Ground mathematical or logical processing blocks using zero-cost ambient parameters drawn directly from students' daily surroundings (e.g., local market pricing grids, sports metrics, seasonal rainfall, agricultural timetables).
* Rule CL-04 (Collective Shared Purpose): Supplement standard individual grading schemas with non-adversarial, whole-cohort milestones or parallel production objectives.
* Rule CL-05 (Real Audience Production): Ensure physical artifacts generated during routine production cycles (mini-books, layout diagrams, posters) are formatted for a visible, immediate local community audience via low-overhead school showcase loops or peer walks.

## Participatory Budgeting (PB) Subroutine Rules
* Rule PB-01 (Resource Constraints Check): Apply PB cards *only* if the educational text features a clear, analytical or real resource allocation trade-off decision points. Skip for foundational phonics/reading tracks.
* Rule PB-02 (Knapsack Voting): Enforce hard-capped boundaries when student groups prioritize items, forcing real arithmetic and mathematical optimization modeling over arbitrary selections.
* Rule PB-03 (Data-Agnostic Process): Ensure zero physical money or cash-handling tasks are assigned to minor students.\n
