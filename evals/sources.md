# Source documents for golden examples

The golden examples summarise these Shikshagraha Commons resources; they don't reproduce them. The eval harness should fetch the originals and extract text at run time, not copy them into this repo. Resource metadata is at `https://commons.shikshagraha.org/api/v1/media/<id>/`, and the file is in its `s3_url`.
